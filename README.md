# 🔒 Shanvi Enterprise - Inventory Management System (Backend)

This repository contains the secure, enterprise-grade backend for the **Shanvi Enterprise Inventory Management System (IMS)**. This powerful server is the backbone of a system currently managing a live inventory valued at over **₹4 Crore (approx. $500,000 USD)**.

Built on the MERN stack, this Node.js application provides a robust, scalable, and secure RESTful API to handle all business-critical operations. The system is deployed on a dedicated Hostinger VPS, ensuring high availability and performance.

---

## ✨ Core Features & Responsibilities

- 🔐 **Secure Authentication & Authorization:** Implemented JWT-based authentication with role-based access control (RBAC) to ensure that employees can only access data and perform actions relevant to their roles (e.g., Admin, Manager, Staff).
- 📦 **Real-Time Inventory Tracking:** Manages the entire lifecycle of inventory items—from procurement and stocking to sales and dispatch.
- 📈 **Advanced Data Operations:** Handles complex queries for generating reports, tracking stock levels, and providing business intelligence data.
- 🛡️ **Data Integrity & Validation:** Utilizes Mongoose schemas and validation middleware to ensure all data entering the database is accurate and consistent.
- ⚙️ **Scalable Architecture:** Built with a modular structure (routes, controllers, models) to support future growth and the addition of new features.
- 🌐 **Live Production Environment:** Deployed and maintained on a **Hostinger VPS**, demonstrating experience with server management, SSH, and production deployments.
